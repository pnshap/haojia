## 使用方式

先把帖子正文保存成文本文件，文件名形如：

```
11.10｜Switch好价卡带.txt
11.10｜Ps好价光盘.txt
```

### 1、临时导入数据

点击页面右上角的 **「导入 txt 文件夹」** 按钮，选择 txt 所在的文件夹，浏览器会解析并**按增量并入**现有数据，只留在本页内存里：

- 刷新页面即恢复内置数据；

### 2、生成静态页面

```bash
git clone  https://github.com/pnshap/haojia.git
cd haojia

# txt 放进 txt/ 目录后
python3 build.py

# 直接用浏览器打开 index.html 
```


常用参数：

```bash
python3 build.py            # 合并并写入 js/data.js
python3 build.py --list     # 只打印合并计划（会列出 [新增] / [更新] 的文件名），不写文件
python3 build.py --fresh    # 忽略已有 data.js，完全按 txt/ 重建
```

## 手动合并重复的游戏名称

`js/merge.js` 用来将难以被自动合并的同一款游戏的几个项目手动合并成同一项，一行一组：

```js
var GROUPS = [
  ['识质存在', '识智存在'],
  ['星之卡比wii', '星之卡比wi'], 
];
```

- 每行的**第一个是展示名**，后面都为别名；
- **由于游戏命名规则五花八门错综复杂并且雀大人的命名也有点随心所欲再加上本人游戏阅历没那么丰富所以对哪些游戏名称需要合并哪些不需要也没有准确的判断只能根据经验慢慢完善所以难免会有疏漏所以有大手子来pullrequests最好了没有也就将就看吧**
